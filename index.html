Runner exit rule
Close the remaining position if a 15m candle closes through EMA21 against your trade, the opposite setup clears 4/6 gates, or the price loses the last confirmed swing structure.
Never move a stop farther away just to avoid realizing a loss. If the setup invalidates, the statistical premise has changed.

Data sources and upgrade path

No paid API required for core version

Core live market layer

Binance public REST/WebSocket market data provides BTC spot candles and ticker. Binance Futures public endpoints provide mark price, funding and open interest. No API key is embedded in this file.

Optional macro layer

Alpha Vantage can add Treasury yield, Brent crude and other economic series through one key. FRED is an official alternative for macro history. If you later want professional liquidation maps, exchange-level OI aggregation and ETF flow feeds, CoinGlass is the most natural paid crypto-specific upgrade.
